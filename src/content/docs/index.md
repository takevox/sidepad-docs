## できること

- **広いエディタで書く** — 画面の半分を使うエディタで、サイトの入力欄の内容を編集します。書いた内容はそのままサイトの入力欄に反映され、エディタから送信もできます。
- **目次で読む** — 長い Issue や会話を、コメント・発言と見出しの目次でたどれます。目次から引用や見出しをエディタに挿入することもできます。
- **Markdown を楽に書く** — 見出し・リスト・テーブルなどのツールバーと、リストの続きを自動で入力する入力補助があります。

## 対応サイト

| サイト | 対象のページ |
| --- | --- |
| GitHub | Issue・プルリクエストの個別ページ、Issue の新規作成ページ |
| Gemini | 会話の画面、Gem、プロジェクトのトップ |
| ChatGPT | 新しいチャット、会話の画面、プロジェクトのトップとプロジェクト内の会話 |

サイトごとの違いは [サイト別の動作](/guide/sites/) を参照してください。
