## GitHub

### 対象のページ

- Issue・プルリクエストの個別ページ
- Issue の新規作成ページ

リポジトリのトップや一覧ページでは目次とエディタを表示できますが、エディタは読み取り専用になります。

### 既存のコメントの編集

ページ上で既存のコメントの「Edit」を押すと、エディタにそのコメント用の編集タブ（「編集: 投稿者名」）が追加され、エディタで続きを書けます。編集タブを閉じると、ページ側の編集フォームも閉じます。

### 書式

GitHub の Markdown として扱い、ツールバーにタスクリストのボタンが加わります。

## Gemini

### 対象のページ

- 会話の画面（新しい会話を含む）
- Gem
- プロジェクトのトップ（ここから新しい会話を始められます）

### 一覧に戻る

プロジェクト内の会話では、エディタの上部にプロジェクトのトップへ戻るボタンを表示します。

## ChatGPT

### 対象のページ

- 新しいチャット
- 会話の画面
- プロジェクトのトップと、プロジェクト内の会話

### 一覧に戻る

プロジェクト内の会話では、エディタの上部にプロジェクトのトップへ戻るボタンを表示します。

### 新しいチャットへの切り替え

会話の画面から「新しいチャット」に切り替えると、エディタは新しいチャットの入力欄（空）に付け替わります。前の会話に戻ると、その会話の入力欄の内容を読み込み直します。
