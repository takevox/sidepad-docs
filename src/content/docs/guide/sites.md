どのサイトでも、エディタと目次を表示するのは入力欄があるページだけです。それ以外のページでは隠れ、ショートカットキーにも反応しません。開閉の状態は覚えているので、入力欄のあるページに戻ると元どおり表示されます。

隠さずに表示したままにすることもできます（[設定](/guide/settings/) の「入力欄がないページでは隠す」を OFF）。その場合、目次には対象がないことを、エディタには使えないことを表示します。

## GitHub

### 対象のページ

- Issue・プルリクエストの個別ページ
- Issue の新規作成ページ

Issue 一覧、プルリクエスト一覧、リポジトリのトップ、コードのページなどでは隠れます。

### 既存のコメントの編集

ページ上で既存のコメントの「Edit」を押すと、エディタにそのコメント用の編集タブ（「編集: 投稿者名」）が追加されます。続きはエディタで書けます。編集タブを閉じると、ページ側の編集フォームも閉じます。

### 書式

GitHub の Markdown として扱います。ツールバーにはタスクリストのボタンが加わります。

## Gemini

### 対象のページ

- 会話の画面（新しい会話を含む）
- Gem
- プロジェクトのトップ（ここから新しい会話を始められます）

### 一覧に戻る

プロジェクト内の会話では、エディタの上部にプロジェクトのトップへ戻るボタンを表示します。

## ChatGPT

### 対象のページ

- 新しいチャット
- 会話の画面
- プロジェクトのトップと、プロジェクト内の会話

### 一覧に戻る

プロジェクト内の会話では、エディタの上部にプロジェクトのトップへ戻るボタンを表示します。

### 新しいチャットへの切り替え

会話の画面から「新しいチャット」に切り替えると、エディタは新しいチャットの入力欄（空）に付け替わります。前の会話に戻ると、その会話の入力欄の内容を読み込み直します。
