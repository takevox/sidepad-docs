## 一覧（既定の割り当て）

| 動作 | キー |
| --- | --- |
| エディタの表示切替 | <kbd>Alt</kbd> + <kbd>E</kbd> |
| 目次の表示切替 | <kbd>Alt</kbd> + <kbd>T</kbd> |
| エディタを閉じる | <kbd>Esc</kbd> |
| 送信（エディタ内） | <kbd>Ctrl</kbd> + <kbd>Enter</kbd> |
| 操作方法（チートシート）の表示切替 | <kbd>F1</kbd> |
| 見出しレベルを上げる（`#` を追加） | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd>（<kbd>&gt;</kbd>） |
| 見出しレベルを下げる（`#` を減らす） | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>,</kbd>（<kbd>&lt;</kbd>） |

上の割り当ては [設定](/guide/settings/) で変更できます。

## 変更できないキー

次のキーはエディタ内の編集操作で、割り当ては変更できません。

| 動作 | キー |
| --- | --- |
| 空白 2 つを挿入 | <kbd>Tab</kbd> |
| テーブルのセル間を移動 | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + 矢印キー |
| テーブルの行を入れ替え | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>↑</kbd> / <kbd>↓</kbd> |
| 前／次の見出しへ移動 | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>PageUp</kbd> / <kbd>PageDown</kbd> |
| リスト・インデント・テーブル行の自動入力（入力補助が ON のとき） | <kbd>Enter</kbd> |
