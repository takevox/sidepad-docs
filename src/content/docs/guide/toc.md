目次には、ページ内のコメント（AI チャットでは発言）と、その中の見出しを一覧で表示します。

- コメントの項目は「`#番号 投稿者 (日付)`」の形で表示します。Gemini と ChatGPT は発言ごとの日時がないため、投稿者（You / Gemini / ChatGPT）だけを表示します。
- ページをスクロールすると、いま読んでいる位置の項目が目次でも選択されます。

## 操作

| 操作 | 動作 |
| --- | --- |
| 左クリック | その位置へジャンプ |
| 右クリック | コメントなら引用を、見出しなら見出しの文字をエディタに挿入 |
| <kbd>Alt</kbd> + <kbd>T</kbd> | 目次の表示切替 |

## ツールバー

目次の上部には、左から次のものが並んでいます。

| 位置 | 内容 |
| --- | --- |
| 左 | 表示する見出しの深さ（どのレベルの見出しまで表示するか） |
| 中央 | 「目次を再読み込み」「ページの一番上に移動」「ページの一番下に移動」の 3 つのボタン |
| 右 | 目次の配置を切り替えるボタン |

「目次を再読み込み」は、ページではなく目次を作り直します。目次は自動で更新されますが、内容がずれたときに使います。ページの一番上・一番下への移動は、GitHub ではページ全体を、Gemini と ChatGPT では会話の領域をスクロールします。

## 配置

目次の配置は、次の 3 つから選べます。

- エディタと反対側の画面端
- エディタの左
- エディタの右
