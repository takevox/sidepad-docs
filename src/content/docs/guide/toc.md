目次には、ページ内のコメント（AI チャットでは発言）と、その中の見出しを一覧で表示します。

- コメントの項目は「`#番号 投稿者 (日付)`」の形で表示します。Gemini と ChatGPT は発言ごとの日時がないため、投稿者（You / Gemini / ChatGPT）だけを表示します。
- ページをスクロールすると、いま読んでいる位置の項目が目次でも選択されます。

## 操作

| 操作 | 動作 |
| --- | --- |
| 左クリック | その位置へジャンプ |
| 右クリック | コメントなら引用を、見出しなら見出しの文字をエディタに挿入 |
| <kbd>Alt</kbd> + <kbd>T</kbd> | 目次の表示切替 |

## 表示する見出しの深さ

目次の上部のリストで、どのレベルの見出しまで表示するかを選びます。

## 配置

目次の上部のボタンで、配置を次の 3 つから選びます。

- エディタと反対側の画面端
- エディタの左
- エディタの右
