エディタの上部にある歯車のボタンで設定画面を開きます。設定は Chrome に保存され、Chrome の同期を有効にしている場合は他の端末にも引き継がれます。

## 一般

| 項目 | 内容 |
| --- | --- |
| エディタを自動で開く | 対象のページを表示したときにエディタを開きます。 |
| 目次を自動で開く | 対象のページを表示したときに目次を開きます。 |
| レイアウトを記憶 | エディタの表示位置・目次の配置・見出しの深さをサイトごとに覚え、新しく開いたページでも使います。OFF でも、同じタブ内でのページ移動では表示状態を維持します。 |

「覚えたレイアウトを消去」ボタンで、サイトごとに覚えたレイアウトをすべて消去します。

## フォント

UI・目次・エディタのそれぞれについて、フォントと文字サイズ（8〜32px）を指定できます。「既定」ボタンで元に戻します。

## ショートカットキー

割り当てを変えたい動作のボタンを押してから、割り当てるキーを押します。「既定」ボタンで元に戻します。対象の動作は [ショートカットキー](/guide/shortcuts/) を参照してください。
