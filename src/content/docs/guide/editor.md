エディタは画面の左右どちらかに表示され、サイトの入力欄と内容を同期します。

## 表示位置

エディタの上部にあるボタンで、画面の左右どちらに表示するかを切り替えます。

## 送信

<kbd>Ctrl</kbd> + <kbd>Enter</kbd>、またはエディタの送信ボタンで、サイトの入力欄の内容を送信します。

送信できないページ（一覧ページなど）では、エディタは読み取り専用になり、送信ボタンも押せなくなります。

## 一覧に戻る

Issue や会話を開いているとき、エディタの上部に一覧へ戻るボタンを表示します。

| サイト | 戻り先 |
| --- | --- |
| GitHub | Issue なら Issue 一覧、プルリクエストならプルリクエスト一覧 |
| Gemini・ChatGPT | プロジェクト内の会話なら、そのプロジェクトのトップ |

エディタと目次は開いたまま移動します。

## タブ

エディタには常設の「新規コメント」タブがあります。GitHub で既存のコメントの編集を始めると、そのコメント用の編集タブが追加されます。詳しくは [サイト別の動作](/guide/sites/) を参照してください。

## ツールバー

入力内容は Markdown として扱い、ツールバーから書式を付けられます。

| ボタン | 動作 |
| --- | --- |
| 入力補助 | Markdown の入力補助の ON / OFF（タブごと） |
| 見出し | 押すたびに見出しのレベルを切り替え |
| 太字・斜体 | 選択した文字を囲む |
| 引用 | 選択した行を引用にする（もう一度押すと外す） |
| コード | コードを挿入 |
| リンク | リンクを挿入 |
| 箇条書き・番号付きリスト | 選択した行をリストにする（もう一度押すと外す） |
| タスクリスト | 選択した行をタスクリストにする（GitHub のみ） |
| テーブル | 行数 × 列数を選んでテーブルを挿入 |

## キー操作

| キー | 動作 |
| --- | --- |
| <kbd>Tab</kbd> | 空白 2 つを挿入 |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd>（<kbd>&gt;</kbd>） | 見出しレベルを上げる（`#` を追加） |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>,</kbd>（<kbd>&lt;</kbd>） | 見出しレベルを下げる（`#` を減らす） |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + 矢印キー | テーブルのセル間を移動 |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>↑</kbd> / <kbd>↓</kbd> | テーブルの行を入れ替え |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>PageUp</kbd> / <kbd>PageDown</kbd> | 前／次の見出しへ移動 |
| <kbd>Enter</kbd> | リスト・インデント・テーブル行の続きを自動で入力（入力補助が ON のとき） |

ショートカットキーの一覧と変更方法は [ショートカットキー](/guide/shortcuts/) を参照してください。
