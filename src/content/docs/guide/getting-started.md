## インストール

Chrome ウェブストアで「Sidepad」を検索し、Chrome に追加します。

## エディタと目次を開く

対象のページ（GitHub の Issue、Gemini や ChatGPT の会話など）を開くと、エディタと目次が自動で開きます。開いたエディタや目次は、元のページの横に並びます。元のページはその分だけ縮むので、内容が隠れることはありません。

キーで開いたり閉じたりもできます。

| キー | 動作 |
| --- | --- |
| <kbd>Alt</kbd> + <kbd>E</kbd> | エディタの表示切替 |
| <kbd>Alt</kbd> + <kbd>T</kbd> | 目次の表示切替 |
| <kbd>Esc</kbd> | エディタを閉じる |

自動で開きたくない場合は、[設定](/guide/settings/) の「エディタを自動で開く」「目次を自動で開く」を OFF にします。

Issue 一覧やコードのページなど、入力欄がないページではエディタと目次を隠します。入力欄のあるページに戻ると、また表示されます。

## 書いて送信する

1. エディタに文章を書きます。書いた内容はそのままサイトの入力欄に反映されます。
2. <kbd>Ctrl</kbd> + <kbd>Enter</kbd> を押すか、エディタの送信ボタンを押して送信します。

送信するとサイトの入力欄が空になり、エディタも空に戻ります。続いて、投稿したコメントの位置へ移動します（[エディタ](/guide/editor/#送信) を参照）。

## 操作方法を確認する

エディタを開いているときに <kbd>F1</kbd> を押すと、操作方法の一覧（チートシート）を表示します。設定したショートカットキーと、機能の設定状況も確認できます。もう一度 <kbd>F1</kbd> を押すか、<kbd>Esc</kbd> かクリックで閉じます。

エディタの上部、歯車の右にある（？）ボタンを押すと、このヘルプを新しいタブで開きます。

## 表示言語

Sidepad の画面は日本語と英語に対応しています。最初はブラウザの言語に合わせて表示します。[設定](/guide/settings/) の「表示言語」で切り替えられます。
