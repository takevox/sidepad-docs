## Open the settings

Open them in either of these ways:

- The gear button at the top of the editor
- The extension's options page (in `chrome://extensions`, open Sidepad's "Details" → "Extension options", or right-click the Sidepad icon in the toolbar → "Options")

The options page lets you change settings even when the editor isn't open, or when you're on a page where it's hidden.

Changes are saved immediately and applied to your other open tabs. If Chrome sync is on, they're also carried over to your other devices.

## General

| Item | Default | Description |
| --- | --- | --- |
| Language | Automatic | The language of Sidepad's screens (Automatic, 日本語, English). Automatic follows your browser's language. |
| Open the editor automatically | On | Opens the editor when you view a supported page. |
| Open the table of contents automatically | On | Opens the table of contents when you view a supported page. |
| Remember layout | On | Remembers the editor position, table of contents position and heading depth for each site, and uses them on newly opened pages. Even when off, the layout is kept while you move between pages in the same tab. |
| Hide on pages without an input field | On | Hides the editor and table of contents on pages without an input field, such as issue lists and code. When off, they stay visible and the layout doesn't change as you move between pages. |
| Jump to the posted comment after sending | On | After you send a new comment (a message in AI chats), jumps to where the posted comment appears. Same as the editor's "Jump" switch. |

"Clear saved layouts" clears the layouts remembered for every site.

## Display

You can set the font and font size (8–32px) for the UI, the table of contents and the editor. "Default" resets them.

## Keys

Click the button for the action you want to change, then press the key to assign. "Default" resets it. See [Keyboard shortcuts](/en/guide/shortcuts/) for the actions.
