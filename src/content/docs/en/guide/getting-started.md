## Install

Search for "Sidepad" in the Chrome Web Store and add it to Chrome.

## Open the editor and table of contents

When you open a supported page (a GitHub issue, a Gemini or ChatGPT chat, etc.), the editor and table of contents open automatically next to the page. The page shrinks to make room, so none of its content is hidden.

You can also open and close them with keys.

| Key | Action |
| --- | --- |
| <kbd>Alt</kbd> + <kbd>E</kbd> | Toggle editor |
| <kbd>Alt</kbd> + <kbd>T</kbd> | Toggle table of contents |
| <kbd>Esc</kbd> | Close editor |

If you don't want them to open automatically, turn off "Open the editor automatically" and "Open the table of contents automatically" in the [settings](/en/guide/settings/).

On pages without an input field, such as issue lists and code, the editor and table of contents are hidden. They reappear when you return to a page with an input field.

## Write and send

1. Write in the editor. What you write is reflected in the site's input field as you type.
2. Press <kbd>Ctrl</kbd> + <kbd>Enter</kbd> or click the editor's Send button.

After sending, the site's input field and the editor are cleared, and the page jumps to the comment you posted (see [Editor](/en/guide/editor/#send)).

## Check the controls

While the editor is open, press <kbd>F1</kbd> to show a list of controls (a cheat sheet). It also shows your keyboard shortcuts and current settings. Press <kbd>F1</kbd> again, press <kbd>Esc</kbd>, or click to close it.

## Language

Sidepad's interface is available in Japanese and English. At first it follows your browser's language. You can switch it with "Language" in the [settings](/en/guide/settings/).
