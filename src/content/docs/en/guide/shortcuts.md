## Shortcuts (default assignments)

| Action | Key |
| --- | --- |
| Toggle editor | <kbd>Alt</kbd> + <kbd>E</kbd> |
| Toggle table of contents | <kbd>Alt</kbd> + <kbd>T</kbd> |
| Close editor | <kbd>Esc</kbd> |
| Send (in editor) | <kbd>Ctrl</kbd> + <kbd>Enter</kbd> |
| Toggle controls help (cheat sheet) | <kbd>F1</kbd> |
| Raise heading level (add `#`) | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd> (<kbd>&gt;</kbd>) |
| Lower heading level (remove `#`) | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>,</kbd> (<kbd>&lt;</kbd>) |

You can change these in the [settings](/en/guide/settings/).

## Keys you can't change

These are editing keys in the editor, and their assignments can't be changed.

| Action | Key |
| --- | --- |
| Insert two spaces | <kbd>Tab</kbd> |
| Move between table cells | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + arrow keys |
| Swap table rows | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>↑</kbd> / <kbd>↓</kbd> |
| Go to previous / next heading | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>PageUp</kbd> / <kbd>PageDown</kbd> |
| Auto-continue lists, indents and table rows (when input assist is on) | <kbd>Enter</kbd> |
