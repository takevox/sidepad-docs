## What you can do

- **Write in a roomy editor** — An editor that takes half the screen edits the site's input field. What you write is reflected in the site's input field as you type, and you can send it from the editor.
- **Read with a table of contents** — Follow long issues and chats through a table of contents of comments, messages and headings. You can also insert quotes and headings into the editor from it.
- **Write Markdown with ease** — A toolbar for headings, lists, tables and more, plus input assist that continues lists automatically.
- **Japanese and English** — The interface follows your browser's language, and you can switch it in the settings.

## Supported sites

| Site | Pages |
| --- | --- |
| GitHub | Individual issue and pull request pages, the new issue page |
| Gemini | Chats, Gems, project home pages |
| ChatGPT | New chat, chats, project home pages and chats in projects |

See [Site-specific behavior](/en/guide/sites/) for the differences between sites.
